# 正式出片前的逐镜校正

1. 按镜头在 1920×1080（竖屏为 1080×1920）画面上标注地平线、脚底或轮子接地点、可通行区域、与角色同景深的比例参照。路线拐点标在路面上。斜向桥、台阶、桌案、栏杆和前景遮挡都要结合实际背景核对。
2. 在项目的 page/blocking.json 写入 width、height、sizes、shots。每个镜头必须有 ground=[地平线Y,基准成人显示高度,基准脚点Y]、surface=[脚点最小Y,最大Y]、action、camera.intent 和 camera.zoom=[最小倍率,最大倍率]。坐卧、儿童、车马组合用对应姿态系数；组合图按实际马肩或车轮位置换算。可针对角色写 surfaces、sizes。狭窄、斜向或弯曲路径用 corridor 多边形约束，特殊走位可提供镜头内单独的 corridors[角色]。同一景别对照成人、儿童、马匹和道具；分层景深由脚点换算。镜头中的台阶或高台另标基准。
3. 行进的图层填写 routes[精灵名]={points:[[故事秒,x,y],...],view:"side",facing:"right"}。按故事时刻在原画布坐标插值，自动调整脚点、朝向和透视大小。斜向纵深移动使用适配的四分之三、背面等姿态并注明 view。遇到错误朝向更换素材或调整机位；检查脚步、轮轴与实际行进速度。局部探身、伸手等动作写入 action；位移超过自身高度 65% 的特殊非行走动作须在 gestures[精灵名] 逐项说明。
4. 背景推拉和主体走位分开设计，比较运镜的起点、中点、终点。转场、急停、遮挡交接和换姿势处追加帧。检查焦点、接地、方向连续性、同景深比例、字幕遮挡、边缘与景别变化；看连续动作确认没有滑步、跳轴、漂移、抽动。
5. 使用脚本目录下的 stage-audit.mjs 对项目执行预检。脚本通过浏览器读取实际动画，每 0.2 秒与关键点检查，保存各镜头首段、中段、尾段画面。逐镜查看这些画面，并通过同目录 motion.mp4 的连续动态预览检查动作。发现错误就调整背景、姿势、尺寸或运镜，然后重新运行。执行 Agent 完成复核即可。
6. 在 build/stage-audit/review.json 中保存 result.json 的 digest，以及 shots 对象。每个镜头单独记录 route（运动路径与接地）、scale（主体和物体比例）、camera（运镜、构图与遮挡）的实际观察。静止画面也记录其静止关系。未完成全部镜头、预检失败或文件指纹变化，正式渲染和混音封装都会退出。新角色导入时先验证原生透明 PNG；裁边只裁透明外框，保留柔和边缘的 Alpha。
7. 用 scripts/render_checked.sh 项目绝对路径 输出目录正式渲染，再按 SKILL.md 使用 mix_voice.py。旧工程迁移时将本技能 assets/engine/ 中 engine.js、blocking.js 同步至 lib/，在 page/index.html 的 story.js 之前载入 blocking.js，按实际镜头补全标定。人物仍可在 put 里做旋转、挤压和局部动作。

## 步态与肢体完整性（导出必检）

逐张放大独立动作图，沿肩、肘、袖口、手掌检查连接、数量、前后遮挡；同时检查腿脚和手持道具。遇到多手、残袖、漂浮肢体或旧姿势残影，先修素材或动画图层。双臂连续摆动时，可固定一套躯干，补全衣袍，分别以两个肩点驱动远臂和近臂，按远臂、躯干、近臂的顺序绘制；每帧清空角色画布。

为每个步态循环和造型切换镜头在 shots 对应项填写 limbChecks 数组。每项包含 name、start、end（成片秒数）和 crop=[左,上,宽,高]。循环覆盖至少一个完整周期，造型切换包括前后相邻帧；裁区覆盖整个动作范围。预检逐帧输出 30 fps 局部 PNG。执行 Agent 对照独立姿势和连续帧，检查多肢、残影、断裂、跳位与遮挡，针对每项把实际观察按顺序写入 review.json 的 shots[镜头].limbs 数组。存在问题时先改再重新预检。缺少采样帧或复核记录时停止正式导出。

第三人称镜头使用清晰的独立背景原图。仅在第一人称主观看自己双手或手中道具时，可按焦点虚化远景，同时校准手与背景的透视，保留左右完整袖口。
