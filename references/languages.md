# 语言、声音与字幕

新项目按主流程的四种语言预设选择，另选生词贴开或关。用户可直接说“纯中文”“纯英文”“英文讲述、双语字幕”或“中文讲述、双语字幕”。“双语生词版”是英文讲述、英文在上和中文在下的双语字幕，并开启生词贴。已有项目沿用其设置。

在 `assets/narration.json` 的 `voice.lang` 写 `zh` 或 `en`。分场台词写入同名字段，语音发音替代词可写在 `tts`。旁白与字幕分别处理，翻译不送入另一遍配音。英文版将片名、地点卡和片尾一并译成英语。

- LibTV AI 使用 `libtv_story.py vo`，按旁白语种设计音色并朗读对应台词。
- 系统朗读先执行 `say -v '?'`，选择本机已安装的普通话或英语常规声音，再运行 `python3 <skill>/scripts/system_voice.py <项目> --voice <声音名称>`。系统朗读直接走本地 macOS。
- 自带录音沿用主流程的 `--from-recording`，把实际口播语种传给 `--lang`。

用 `voice_prep.py <项目> --lang zh` 或 `--lang en --max-clause 54` 对齐。先制作单语字幕并读取 `assets/narration.json` 的子句。双语版由执行 Agent 逐条翻译，保留语气、人名与诗文含义，在同目录创建 `subtitle_translations.json`。每个旁白 id 对应按时间排列的数组，每项包含逐字复制的 `source`（含高亮括号）与 `translation`。有 clauses 时 source 取子句 text，整句单独显示时取该语种台词。

在 narration.json 顶层设置 `"subtitleMode": "bilingual"`，再运行 `voice_prep.py <项目> --captions-only --lang <zh或en>`。中英文共享同一进出时间。回读页面和导出的 SRT，验证英文单语无空白中文行、双语逐条上下对应、两行字幕避开手部和关键道具。

## 生词贴

- 开启时，按语境选少量值得解释的英文词。每张贴呈现英文词、国际音标和简短中文释义。默认使用美式音标，按首次出现的顺序展示，一次一张，停留约四秒。根据镜头留白摆放，避开双语字幕、人物脸部、手和道具。
- 在 `assets/narration.json` 对应的 `lines[].cards` 中写入词贴。英文旁白使用口播中实际出现的词形作为 `atWord`，中文旁白使用对应的中文词作为 `atWord`；贴上展示的英文词放在 `title`。例如中文旁白念到“余烬”时，使用下面的卡片。英文旁白念到 ember 时，将 `atWord` 改成 `ember`。
  
  ```json
  {"atWord":"余烬","title":"ember","tag":"/ˈembɚ/","sub":"余烬，仍在发红的炭火","hold":4}
  ```
- 对齐前写入卡片，回读 `lines[].words` 的起点；若口播使用意译，按对齐后的分句写相对该场旁白起点的 `offset`。核对词贴在实际画面中有足够阅读时间。
- 关闭时，省略生词卡及其自动生成用的 `vocab` 映射。人物卡、年份卡和字幕重点词仍按各自设置处理。单语预设生成页面字幕时仅保留所选语种；词贴内容单独展示。双语预设按旁白语种在上、译文在下排版，导出 SRT 时用同样的行序。
