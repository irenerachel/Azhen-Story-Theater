# 出图工具策略、提示词与画风模板

## 工具选择与回退规则

1. **默认优先使用系统自带的生图工具**（如当前宿主环境内置的 `imagegen` / `image-generator` 等）：
   - 背景空镜（无需透明）：默认用系统自带生图工具直接生成，保存到 `assets/raw/B1.png`、`B2.png` …
   - 透明素材（角色设定表、角色姿势、车马与船只、独立道具、前景遮挡层、主讲人头像）：优先检查并调用系统自带生图工具的原生透明 PNG 能力（如设置 `transparent_background=true`），出角色姿势时传入设定表作为参考图，保存到 `assets/raw/C01.png`、`H_avatar.png` …
2. **回退调用 LibTV（`scripts/libtv_story.py`，默认模型 `Lib Image 2.5 Pro`，`2K` 分辨率，透明素材自动设置 `background=transparent`）**：
   - **仅当系统没有可生成原生透明 PNG（带真实 Alpha 通道）的生图工具时**，再调用 LibTV 生成需要透明底的素材（`sheet` / `pose` / `host`）；若系统完全没有自带生图工具，背景空镜（`bg`）也一并回退到 LibTV。
   - 若背景用系统自带工具、透明层回退 LibTV，保持完全相同的画风描述，并把设定表通过 `upload-sheet` 上传至 LibTV 画布以维持角色一致性。

## 七套可选故事画风（开工提纲阶段推荐给用户挑）

### 埃尔热欧洲清线漫画（默认）

```text
埃尔热欧洲清线画风，欧洲清线漫画插画画风，人体比例简化而清楚，头部略大、脸型圆润，眼睛以小黑圆点表现，眉毛是短弧线，鼻子为突出圆钝形，嘴巴用一两笔弧线概括，五官位置准确且表情易读。使用稳定、整洁、粗细近乎一致的黑色墨线勾勒外轮廓与必要内部结构，线条连续闭合，衣褶数量克制，细节通过清楚形状与分区交代。色面均匀不透明，稍含旧印刷感，阴影几乎省略，不用渐变、排线和厚重纹理塑形。边缘锐利，体积主要由轮廓、遮挡和少量衣褶建立，整体清晰、朴素、轻快，具有经典彩色冒险漫画的叙事可读性。
```

### 探险活宝软线扁平

```text
用探险活宝软线扁平画风，轻松扁平的软线二维卡通画风，头部与躯干由圆角长方和简单椭圆构成，四肢细长如柔软面条，关节不强调骨性结构，手指短小简化，脚形为小块圆钝形。面部以两点小眼睛和一段弧形嘴线表达，鼻子和复杂眉毛常省略，表情朴素而亲切。色轮廓细而均匀，线条流畅，弯曲自然，内部细节极少。色域完整，阴影基本省略，表面无写实纹理。形体轻盈松弛，比例可适度拉长或变圆，整体带手绘简笔画的直接感、轻微荒诞感与温和幽默。
```

### 1. 复古绘本平涂风（适合人物传奇、市井故事、温情幽默）
> 复古手绘绘本平涂插画风，松弛有力的深墨色变粗细轮廓线，形体略带夸张和幽默感，表情靠眼睑高低、眉毛倾斜与嘴角细节传递；纯平涂色块与轻微纸纹肌理，无 3D 渲染、无写实光影；背景采用低饱和暖灰、赭石、旧青蓝或米黄，主体人物饱和度高一档，主体与背景层次分明。

### 2. 现代纪实描边插画风（适合商业人物传记、科技创业史、社会观察）
> 现代编辑部插画与纪实漫画结合风格，干净利落的等宽深墨轮廓线，人物比例写实略带概括，服饰与时代器物细节考究；低饱和扁平配色（藏青、陶土棕、冷灰、暖米白）配一到两个点睛色（如琥珀橙）；画面简洁留白充足，无炫光无立体渲染。

### 3. 国风淡彩手绘风（适合历史人物、传统文化、民间奇闻）
> 现代新国风淡彩连环画风格，毛笔勾线质感，线条流畅有顿挫，人物神态传神；宣纸暖米色基调，矿物淡彩平涂与柔和晕染（靛蓝、赭石、朱砂、藤黄），保留手工纸绘呼吸感，干净清爽不杂乱。

### 4. 黑白漫画点睛色风（适合悬疑奇案、硬核逆袭、反差爽感故事）
> 极简黑白线条漫画风格，干净硬朗的钢笔墨线与适度网点阴影，全画面以黑白灰纸面为主调，仅在核心人物围巾、关键信物或情绪爆点处保留单一高亮颜色（如朱红或亮金），电影分镜感强，留白克制。

### 彩铅报刊漫画

彩色报刊人物漫画。用轻重有变化的钢笔勾出轮廓，以顺着脸颊、衣褶和物体体积走向的交叉排线塑形，再用彩铅与透明水彩叠色。人物头部略大，眉眼、鼻形和手势富有表情。背景建筑和道具使用同样的笔触，保留纸纹。取钴蓝、砖红、木褐与暖肤色。按本次故事设计人物、场景和动作。空镜单独绘制，每个人物和需要独立运动的道具分别输出透明素材。

## 通用制作技法：逐笔分层

逐笔分层默认关闭，七种画风均可按用户选择开启。背景、前景遮挡、人物、道具、手写文字、笔尖和字幕分别控制。每个对象按画风实际使用的笔触拆层。清线与软线扁平按轮廓、色块显现；复古绘本和现代纪实保留各自的描边与铺色；国风淡彩分墨线、淡彩晕染；黑白点睛分墨线、网点、点睛色；彩铅报刊漫画分轮廓、排线、底色。
- **绘制顺序**。旁白提到对象时，笔尖沿实际路径勾轮廓，再依所选画风完成其余笔触与色层。先画承担叙事的眉眼、手势或道具。汉字按笔顺显现，笔尖跟随当前笔画终点。

## 1. 角色设定表（第一张，确认后才出其余图）

比例 `16:9`（**需原生透明 PNG**：优先用系统自带支持透明 PNG 的生图工具生成并存为 `assets/raw/char-sheet.png`；若系统无此能力，用下方 LibTV 命令回退）：
```bash
# 提示词可直接用于系统自带生图工具（开启 transparent_background=true）；以下为 LibTV 回退命令：
python3 libtv_story.py sheet "<画风描述>。原创角色设定图，2到3个角色全身站姿从左到右一字排开，透明背景，角色之间留出空隙，无任何文字标签。
从左到右：
1 <主角时代身份，如：九十年代南方电子市场年轻摊主>：<年龄体型>，<发型脸型>，<穿戴服饰与主色调>。
2 <同主角成年/后期造型或关键配角>：<体型与服饰对比>。" 16:9
```
- 不用受版权保护的影视形象或专有名词；历史/现实人物用身份与年代外貌特征描述（如“九十年代穿深蓝工装夹克、戴黑框眼镜的青年技术员”）。

## 2. 背景空镜

比例与成片一致（默认横版 `16:9`，竖版传 `9:16`）。**默认用系统自带生图工具直接生成**并保存到 `assets/raw/B1.png`；仅当系统无自带生图工具时改用 LibTV。若出竖版背景，务必写明「中下部留出开阔平地给人物站立，上方留空给标题和构图」；横版则写明「中央和中下部留出开阔地面给角色表演」：
```bash
# 提示词默认用于系统自带生图工具；以下为无自带生图工具时的 LibTV 回退命令：
python3 libtv_story.py bg B1 "<画风描述>。手绘动画空镜背景，画面里没有任何人物、动物和文字。<地点与年代细节：前景/中景/远景>，画面中下部留出大片开阔地面方便角色站立走动，整体配色低饱和不抢人物。" 16:9
```

## 3. 角色动作与关键道具（参考角色设定表保持一致）

单人全身推荐 `3:4`，多人同框 `4:3` 或 `16:9`，单独道具 `1:1`。**需原生透明 PNG**：优先使用系统自带生图工具（开启透明底并传入设定表作为参考图，存为 `assets/raw/C01.png`）；若系统没有支持生成透明 PNG 的工具，再调用 LibTV（自动连线 `char-sheet`）：
```bash
# 提示词可用于系统自带生图工具（参考设定图 + transparent_background=true）；以下为 LibTV 回退命令（默认透明底，Lib Image 2.5 Pro）：
python3 libtv_story.py pose C01 "参考{{Image 1}}里第 1 个角色，保持完全一致的长相、发型、服装和画风。单独画他全身，<朝向>，<具体动作与手势>，<表情细节>。全身完整入画不裁头裁脚，不要地面投影，不要背景装饰和文字。透明背景。" 3:4
```
- **手持道具结构写死**：写清楚「双手稳稳托住一只木箱 / 握住同一根工具柄，结构完整连续不断裂」，避免 AI 画重影或断柄。

## 4. 主讲人头像（仅启用 `host.mode = "avatar"` 时需要）

**需原生透明 PNG**：优先使用系统自带支持透明 PNG 的生图工具（存为 `assets/raw/H_avatar.png`）；若系统不支持透明 PNG，再调用 LibTV：
```bash
# 提示词可用于系统自带生图工具（transparent_background=true）；以下为 LibTV 回退命令：
python3 libtv_story.py host H_avatar "<与故事同画风>。正面头肩肖像，角色温和看着镜头微笑，嘴巴自然闭合，背景透明，角色外缘保留原画线色，脸部占画面约60%不过满，四周留边，无文字。" 1:1
```
如果要做闭嘴/张嘴双帧切换（不用算法嘴型），再加生成一张 `H_talk`：「保持{{Image 1}}角色五官发色服饰完全一致，改为微张嘴正在讲话的表情，其余不变」。

## 遇到内容过滤拦截时的改法

1. 去掉敏感具体人名、商标与现代政治符号，改写为年代职业特征描述（例如“穿深色西装站在老式电视机旁的中年程序员”）。
2. 避免写“打斗、流血、跪地”等高风险动词，改用喜剧卡通夸张动作或背影对峙，再用代码特效（`shake`、`speed`、`puff` 烟团）配合音效表现冲突感。
3. 同一提示词连续失败两次后不要硬顶，改用已有相近姿势图 + 代码位移/旋转/烟团组合替代。
